# 🚢 Titanic Survival Prediction — Model Deployment

Internship project — [AnalystLab Africa](https://www.linkedin.com/company/analystlab-africa)

A deployed machine learning system that predicts whether a Titanic passenger would have
survived, served through both a **FastAPI prediction API** and a **Streamlit web app**.

## 📖 Problem Statement

Given a passenger's characteristics (class, sex, age, family size, fare, etc.), predict
whether they would have survived the Titanic disaster. This is a binary classification
problem, built on the classic Kaggle Titanic dataset (891 passengers).

## 🧠 Model Used

- **Algorithm:** Random Forest Classifier
- **Tuning:** GridSearchCV + RandomizedSearchCV, validated with 5-fold stratified cross-validation
- **Best parameters:** `n_estimators=200, max_depth=None, min_samples_split=5, min_samples_leaf=2`
- **Performance:** Accuracy 79.3%, F1 0.722, ROC-AUC 0.850 (see the Feature Engineering &
  Model Optimization notebook for full training details)
- **Features used by the model:** `Age`, `Fare_log`, `FarePerPerson_log`, `Title_Mr`, `Sex_enc`,
  `TicketFreq`, `Pclass_Sex_3_male`, `Deck_Unknown`, `FamilySize`, `Pclass`,
  `Pclass_Sex_2_female`, `Title_Mrs`

## 🛠️ Technologies Used

Python · Scikit-learn · FastAPI · Uvicorn · Pydantic · Streamlit · Pandas · NumPy · Joblib

## 🔌 API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/` | API info / welcome message |
| GET | `/health` | Health check |
| POST | `/predict` | Returns a survival prediction for one passenger |
| GET | `/docs` | Interactive Swagger UI (auto-generated by FastAPI) |

### Input Format (`POST /predict`)

```json
{
  "Pclass": 1,
  "Sex": "female",
  "Age": 38,
  "SibSp": 1,
  "Parch": 0,
  "Fare": 71.28,
  "Title": "Mrs",
  "CabinKnown": true,
  "TicketFreq": 2
}
```

| Field | Type | Notes |
|---|---|---|
| `Pclass` | int | 1, 2, or 3 |
| `Sex` | string | `"male"` or `"female"` |
| `Age` | float | 0–100 |
| `SibSp` | int | Siblings/spouses aboard |
| `Parch` | int | Parents/children aboard |
| `Fare` | float | Ticket fare paid |
| `Title` | string | `Mr`, `Mrs`, `Miss`, `Master`, `Officer`, or `Royalty` |
| `CabinKnown` | bool | Whether the passenger's cabin was recorded |
| `TicketFreq` | int | Number of passengers sharing this ticket (default 1) |

### Output Format

```json
{
  "prediction": 1,
  "prediction_label": "Survived",
  "survival_probability": 0.9908
}
```

cd titanic_deploy

# 2. (Recommended) Create a virtual environment
python -m venv venv

# 3. Install dependencies
pip install -r requirements.txt

## ▶️ How to Run

**Run the API:**
```bash
uvicorn app:app --reload --port 8000
```
Then visit `http://127.0.0.1:8000/docs` for the interactive Swagger UI, or send requests directly:
```bash
curl -X POST http://127.0.0.1:8000/predict \
  -H "Content-Type: application/json" \
  -d '{"Pclass":1,"Sex":"female","Age":38,"SibSp":1,"Parch":0,"Fare":71.28,"Title":"Mrs","CabinKnown":true,"TicketFreq":2}'
```

**Run the tests** (with the API running in another terminal):
```bash
python test_api.py
```

**Run the Streamlit app:**
```bash
streamlit run streamlit_app.py
```
Then open `http://localhost:8501` in your browser.
